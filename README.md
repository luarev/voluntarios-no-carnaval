# 🎉 Confete Zero — Sistema de Voluntários do Carnaval

> Cadastro de voluntários para a operação de limpeza urbana do Carnaval de Recife e Olinda.

---

## Funcionalidades

- **Cadastro de voluntários** com nome, contato (telefone e/ou e-mail), cidade, bairro e dias disponíveis
- **Listagem** de todos os voluntários cadastrados
- **Edição** do próprio cadastro via código de inscrição (ID)
- **Exclusão** de registros pelo painel administrativo
- **Dois níveis de acesso:** Portal do Voluntário e Painel do Admin
- Seleção de cidade entre **Recife** e **Olinda**, com lista de bairros encadeada
- Seleção visual dos **5 dias do carnaval** (Sábado → Quarta de Cinzas)
- Interface responsiva para celular e desktop

---

1. Clonar este repositório
